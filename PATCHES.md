# Changes we made to upstream code

When you re-sync an app from upstream (steps in `AGENTS.md`, "Re-syncing an app from upstream"),
re-apply these or check whether upstream fixed them. Each changed spot is marked `crm-desk patch`.

| File | What | Why |
|---|---|---|
| `apps/frappe/frappe/utils/redis_wrapper.py` (`ClientCache.__init__`) | Wrapped the client-side-cache connection in try/except + `ping()`, falls back to plain `frappe.cache` | Redis Cloud rejects `CLIENT TRACKING ... REDIRECT` over RESP2, which crashed every request. Only costs a small speed-up (no in-process cache). |
| `apps/frappe/frappe/locale.py` (`get_locale_value`) | `value = None` before `if lang:` | `UnboundLocalError` when there's no language, e.g. in the email-pull background job. Broke incoming email tickets. |
| `apps/frappe/node_utils.js` (`get_redis_subscriber`) | Added `client.on("error", ...)` | node-redis only auto-reconnects when an error listener exists; without it a dropped Redis Cloud connection crashed socketio, and `bench start` then stopped every process. |
| `apps/frappe/package.json` + `apps/frappe/yarn.lock` (Snyk 1) | Removed the `@vue/component-compiler` dependency and regenerated the lockfile. No `crm-desk patch` marker: JSON has no comments. | Unused Vue 2 leftover: nothing in Frappe imports it (the build uses `esbuild-plugin-vue3`). It alone pulled in postcss 5/6/7, json5 0.5.1 and loader-utils 0.2.17, all flagged by Snyk. Upstream did the same on `develop` (frappe/frappe#41167) but not on `version-16`: on re-sync, drop this row once `version-16` has it. |
| `apps/frappe/package.json` + `apps/frappe/yarn.lock` (Snyk 2) | `launch-editor` `^2.2.1` → `2.14.2` (pinned), which pulls `shell-quote` 1.12.0; `resolutions` forces `immutable` `4.3.9` (pulled in by sass). | Snyk: clears both Criticals (immutable prototype pollution, shell-quote command injection) plus the launch-editor command-injection issues. Build/dev-only tools (sass, `bench watch`). On re-sync: drop any line upstream already meets. |
| `apps/frappe/package.json` + `apps/frappe/yarn.lock` (Snyk 3) | `socket.io` `^4.7.1` → `^4.8.4` and `socket.io-client` → `^4.8.3` (resolves 4.8.4); lockfile now has engine.io 6.6.11, ws 8.21.3, socket.io-parser 4.2.7, socket.io-adapter 2.5.8. | Snyk: realtime-server DoS issues (engine.io polling, ws frames/headers, socket.io-parser attachments) that work before login. All the same major version as before. | Snyk: build-tool issues (sass/stylus/cssnano/postcss chains). Only run during `bench build`. Picked fixed releases at least 2 weeks old (postcss-selector-parser 6.1.5 skipped for that reason). On re-sync: drop each entry upstream's lockfile already meets. |
